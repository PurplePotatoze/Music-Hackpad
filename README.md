# Music-Hackpad

Making a Hackpad with Hackclubs guide, it will control apple music or Spotify. This project was really fun and I learned how to use CAD and KiCad to make 3d models and pcbs.

BOM:
- 1x XIAO RP2040
- 4x M3x16mm screws
- 4x M3x5mx4mm heatset inserts
- 6x white blank DSA keycaps
- 6x MX-Style switches
- 2x EC11 Rotary encoders
- 6x through-hole 1N4148 Diodes
- PCB
- Bottom and Top 3D Printed Case

Features:
- Two Rotary Encoders to control volume and brightness
- 6 Keys for flexibility
- USBC Compatibility

# CAD: 
Pretty straight forward, cut out for USB, sleek design, and held together with 4 M3 screws and heatset inserts.
